# El Dashboardio

A neon-glassmorphism family wall dashboard for Home Assistant, built for a
Galaxy Tab S6 (1280x800) running Fully Kiosk. Everything is code — the whole
home view is generated by a Python builder and pushed to HA over its websocket
API, so the entire design iterates in seconds without ever touching the UI
editor.

## What's on the board

- **7-day agenda rail** — full-height, scrollable, one glass block per day,
  events color-coded per family member (parsed from a `Name:` prefix on the
  calendar event, or auto-assigned by source calendar). Titles wrap to 2 lines.
- **Weather pair** — cyan-gradient hourly bars + the stock weekly forecast,
  restyled to match.
- **Quick buttons** — meal plan / family tracker / school bus / shopping lists,
  each with its own accent color, gradient wash, and glowing icon.
- **Chores + points** — a kid-vs-kid scoreboard fed by a FastAPI add-on
  that three-way syncs chores between the dashboard, Cozi lists, and a shared
  Google Sheet. Weekly points, progress bars, a crown for the current leader,
  a win-streak flame, and a claim-code prompt so nobody claims a sibling's
  chore. Daily / weekly / bi-weekly / monthly rotation built in.
- **Grand Champion** — all-time points title card in Old English blackletter,
  with a photo of a majestic goat (the G.O.A.T.) watermarked behind the name.
- **Game-day tiles** — next Bengals / Buckeyes game from ESPN's public API:
  logos, kickoff, venue, TV network, countdown, big `@` on whoever hosts,
  live score while the game is on. Tapping opens a full-season schedule page.
- **Room menu** — six glowing shortcuts into the rest of the HA dashboard.

## How it works

```
build_layout.py      -> generates the home view as Lovelace JSON
                        (custom:button-card JS templates that render raw HTML,
                        card-mod for CSS injection)
make_neon_store.py   -> splices the generated view into your existing
                        dashboard config, pins "Back to Home" buttons,
                        applies backgrounds, patches the weather cards
websocket save       -> hass.callWS({type:'lovelace/config/save', ...})
                        from any logged-in browser tab; no restart needed
```

The chores and game-schedule screens are plain standalone HTML files
(`chores.html`, `gameday.html`) served from `/config/www/` inside iframes —
they talk directly to the chores add-on API and to JSON files that
`gameday.py` refreshes from ESPN every 15 minutes.

## Files

| File | What it is |
| --- | --- |
| `build_layout.py` | Generates the whole home view (layout + neon design system) |
| `make_neon_store.py` | Merges the generated view into a full dashboard config |
| `chores.html` | Chores board web app (claim/reject/edit, codes, sync status) |
| `gameday.html` | Full-season schedule page (`?team=<slug>`) |
| `grocery.html` | Shopping-lists web app (Cozi lists, sections, check-off) |
| `gameday.py` | ESPN next-game sensor + season JSON writer (`/config/bin/`) |
| `chores_totals.py` | points/streak/all-time sensor feed (`/config/bin/`) |
| `chore_catalog.py` | One-shot seeding script for a starter chore catalog |
| `make_chores_sheet.py` | Regenerates the shared Google Sheet workbook |
| `templates.yaml` | Calendar/weather template sensors (14-day agenda feed) |
| `configuration-snippets.yaml` | The `command_line` sensors + font loader config |
| `font_loader.js` | Loads Google Fonts document-wide (shadow-DOM-safe) |
| `bg_neon.svg` | The background: navy gradient, glow blooms, plexus floor |
| `goat.svg` | The Grand Champion's majestic watermark |

The chores engine is its own Home Assistant add-on:
**[cozi-proxy-addon](https://github.com/jeremyfisker90/cozi-proxy-addon)** —
chores API, Cozi sync, Google Sheet sync, frequency rotation, parent rejection.

## Cozi is optional

The chores engine works with **Cozi or Google alone**: set
`cozi_enabled: false` in the add-on (or leave the credentials blank) and
chores sync with the published Google Sheet only. The family calendar is
already platform-neutral (any HA calendar entity), and
`configuration-snippets.yaml` includes a Google-Calendar-based "Today's
dinner" sensor to swap in. See the GOOGLE MODE section in that file.

## Install

Full step-by-step guide: **[INSTALL.md](INSTALL.md)** · what's new: **[CHANGELOG.md](CHANGELOG.md)**. Short version:

1. Install [button-card](https://github.com/custom-cards/button-card),
   [card-mod](https://github.com/thomasloven/lovelace-card-mod), and
   [vertical-stack-in-card](https://github.com/ofekashery/vertical-stack-in-card)
   via HACS.
2. Copy `gameday.py` and `chores_totals.py` to `/config/bin/`, the HTML files,
   `bg_neon.svg`, and `font_loader.js` to `/config/www/`.
3. Merge `configuration-snippets.yaml` and `templates.yaml` into your config;
   restart HA once (the font loader needs it).
4. Install the chores add-on and point the sheet/Cozi settings at your own.
5. Run `python build_layout.py && python make_neon_store.py` against a dump of
   your dashboard's `.storage` config, then save the result over websocket
   (see `make_neon_store.py` comments).
6. Edit the obvious placeholders: bus-tracker URL in `build_layout.py`, claim
   codes in `chores.html`, team ids in `configuration-snippets.yaml`.

Expect to adapt: entity ids, calendar names, and the weather cards are mine.
This repo is a working reference, not a one-click install.

## Hard-won gotchas (read before hacking)

- `custom_fields` content inherits `white-space: nowrap` — set
  `white-space: normal` explicitly or your wrapped text silently truncates.
- A plain inner `<div>` with `overflow-y:auto` + `touch-action:pan-y` scrolls
  on tablets; making the button-card's `ha-card` scrollable does not.
- `@font-face` inside card-mod shadow styles never loads — register fonts at
  the document level via `frontend: extra_module_url` instead.
- Never force `display:flex` or a height onto `vertical-stack-in-card`'s
  `ha-card` — percentage heights inside resolve against it and the layout
  detonates. Tune fixed row heights/margins instead.
- Android WebView renders ~10-15% taller than desktop Chrome — budget your
  vertical sizing for the tablet, not your monitor.
- ESPN's API 403s browser user-agents; fetch server-side with a default UA.
